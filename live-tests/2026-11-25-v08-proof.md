## What v0.8 built

- `free_agent/tools/capture/browse.mjs` — persistent-profile CDP
  driver (JSON-lines RPC): open / read / click / type / upload /
  screenshot / wait, structural perception (visible text +
  interactive elements with stable refs; password fields flagged
  SECRET), challenge detection (Arkose / hCaptcha / reCAPTCHA /
  "verify you are human" / emailed-code and phone prompts),
  human pacing. Profile: `~/.freeagent/browser-profile` (host-only,
  0700, gitignored) — sessions persist between runs.
- `free_agent/browsertools.py` — loop tools: `browser_open`,
  `browser_read`, `browser_click`, `browser_type` (REFUSES
  password/secret fields), `browser_type_secret` (types a vault
  value by key name — the value never enters model context,
  traces, or logs), `browser_upload` (sandbox- or assets-confined),
  `browser_screenshot`, `browser_wait`; `vault_gen_secret`
  (generates a strong password into the encrypted vault, returns
  ONLY the key name); `vault_record_account` (metadata-only
  account record); X lane: `x_session_status` (handle read from
  the page, never from cookies), `x_read_feed`, `x_search`,
  `x_post` (timeline-verified, ≥90 s interval, copy rules enforced
  in code).
- Sentinel gates: no authorised domains in the spec = no browsing
  at all; navigation outside the spec's domain allowlist is denied
  and post-click drift is reported; `x_post` is denied by default —
  Lille's OWN account may post within policy, Ethuram's account
  requires the spec's explicit `post approved: yes`.
- Sweep integration: the sweep's X surface is backed by the
  browser session when one exists (checked-via-session, with
  counts); without a session it stays NOT CHECKED with the reason.
- Payload discipline (new, driven by the attempts below):
  per-spec tool-schema subsetting (the full 32-tool set is
  13.2 KB of schemas; a browser spec now sends 5.1 KB), a loop
  history budget with deterministic compaction of older
  observations (the on-disk trace keeps everything), and a
  per-observation cap.
